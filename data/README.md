# data/

`Human_behavioral_performance.csv`: human four-alternative categorization accuracy (%) per occlusion
level with and without the backward mask, with the reported error half-width. Values are taken from
Rajaei et al. (2019), *Beyond core object recognition: Recurrent processes account for object recognition
under occlusion*, PLoS Computational Biology 15(5): e1007001. They are drawn as reference lines in Fig. 4C
and Supp. Fig. 5.
